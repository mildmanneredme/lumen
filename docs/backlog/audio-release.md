## Private preparation

`web/scripts/prepare_book_audio.py` reconciles the canonical registry and selected production lineage, verifies each original MP3 hash and 192 kbps stream, and stages JSON only under the ignored `Audiobook/author-audit/web-release/` folder. It cannot upload media or replace production audio. Existing production QA gives the decoded sample clock and normalization measurements, bound to the selected master identity and QA hash.

The registry currently contains **12,922 canonical sentences** across 91 tracks, with **182 independent recordings**, and has SHA-256 `aa24c5df01f74cbf8547f851b87838362aff1f327d63ef8e0459d033aa577a5e`.

The source approval is captured once in `author-approval.json`, with the explicit chat statements, decision date, capture timestamp, registry hash, and each recording's audio/text/selection hashes. Re-running preparation rejects a changed source set; the existing author decision cannot silently approve a new take or manuscript revision. Hash-addressed copies remain immutable, while convenience indexes are written atomically without following file symlinks.

```sh
# Initial capture of this session's already authorized, source-bound decision.
python3 web/scripts/prepare_book_audio.py --record-author-approval

# Refresh timing reports from saved evidence without decoding or changing audio.
python3 web/scripts/prepare_book_audio.py --align-only
```

## Independent narrator timing

Both narrators now have local Whisper word timestamps for all **248 selected raw clips each**. Charon's 248 caches came from its current production QA; Autonoe's 248 caches were measured independently in this release with the already installed small model. The project-local MLX environment and Whisper models run offline; no API request, model download, or narration generation is used. MLX needs Metal access on this machine.

```sh
Audiobook/v6/local-asr-env/bin/python web/scripts/prepare_book_audio.py --transcribe-missing

# After the single GPU transcription worker has finished:
Audiobook/v6/local-asr-env/bin/python web/scripts/prepare_book_audio.py --align-only --refine-gaps
```

Each cache must match the selected raw audio hash, exact generation request hash, and exact expected text. Word timestamps are translated through the production QA's conserved raw chunk order, outer trim, and added head/tail samples. Internal silence removal is rejected. Timing maps bind each narrator's own final MP3 hash and decoded duration; one narrator's timing is never copied to another.

Written/spoken numbers, initialisms, known brand spacing, and the production's explicit countdown substitutions are normalized for comparison only. Displayed prose remains unchanged. Minor ASR spellings can use their observed word interval when two exact neighboring words on both sides establish the position; these substitutions remain visible in the confidence report. Zero-length ASR words cannot create a cue. A sentence with no measured interval, or fewer than 80% of its comparison tokens anchored, leaves the strict complete map pending rather than receiving an invented timestamp. Schema-2 records these positions as explicit null gaps; partial word fragments cannot drive highlighting, voice mapping or painting reveals.

For ASR omissions, a second pass uses the already installed medium model on bounded windows between neighboring measured words. It retains the measured words outside those windows and records the original cache hash, refinement model hash, decoder settings, and exact rechecked windows. Narration stays unchanged. This pass may recover recognizer omissions; it does not certify audio content or imply a human listening review.

Each returned window is serialized through strict JSON before clock validation, so backend float subclasses preserve their measured values. Nonfinite, reversed, or out-of-source clock candidates are discarded; their rejected-window evidence is retained, the original words remain unchanged, and other windows continue. A failed or inconclusive ASR recheck never proves that narration omitted a sentence. Remaining gaps carry explicit `syncStatus: unavailable` and null start/end values for the private reader's release contract.

If the recognizer overlaps the measured words on either side of a missing sentence, the recheck region spans those actual measured endpoints and records the overlap. This region only bounds a recognition attempt; the missing sentence still has no start or end cue.
